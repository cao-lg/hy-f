运算符优先级

记不住优先级？加括号最保险！

优先级从高到低

**幂运算最高
* / // %乘除取余

比较/逻辑优先级

not > and > or
（实际写的时候加括号更清晰）

优先级示例
# 先算乘法，再算加法
2 + 3 * 4 = 14 (不是20)

# 括号最优先
(2 + 3) * 4 = 20

# BMI计算：先算平方
weight / (height ** 2)

项目任务：BMI计算器

项目名称

BMI计算器

BMI（身体质量指数）是国际上常用的衡量人体胖瘦程度的标准。本项目综合运用本周所学的运算符知识。

功能需求

  • ✓input()获取身高(m)和体重(kg)
  • ✓算术运算符计算BMI（注意优先级！）
  • ✓比较/逻辑运算符判断BMI区间
  • ✓输出BMI值和健康评估

BMI 参考标准

BMI < 18.5 偏瘦 18.5-24 正常 24-28 偏胖 BMI > 28 肥胖
BMI公式
# BMI = 体重 / 身高的平方
# 注意括号，先算平方！
bmi = weight / (height ** 2)

if bmi < 18.5:
    result = "偏瘦"
elif bmi < 24:
    result = "正常"
