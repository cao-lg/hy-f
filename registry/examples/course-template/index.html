模板说明

本模板基于 Hyperframes 视频渲染框架构建，每个课程页面包含 7 个幻灯片： 标题页 → 教学目标 → 知识点讲解 → 代码示例 → 课堂练习 → 课后作业 → 项目任务

模板文件结构
  • index.html (入口页)
  • week1.html (第1周完整模板)
  • week2.html (第2周完整模板)
  • week3.html (第3周完整模板)
  • compositions/ (幻灯片组件)
  • configs/ (课程配置文件)
