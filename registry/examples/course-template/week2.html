什么是变量？

变量是贴了标签的盒子

age = 18

拿了一个盒子，贴上「age」标签，往里面放了数字18

为什么需要变量？因为世界是会变的。今年18，明年就19了。有了变量，只需要说「把age加1」就行。

变量命名规范

✓ 可以这样命名

  • name, age, score
  • student_age, max_score
  • name2, count3

✗ 不能这样命名

  • 2name (不能以数字开头)
  • my name (不能有空格)
  • my-name (不能有特殊符号)

大小写敏感

age 和 Age 是不同的变量！

💡 建议

给变量起有意义的名字，student_age 比 a 好理解一万倍

赋值操作

注意：Python 里的 = 不是数学里的等于，而是赋值

age = 18

意思是：把 18 这个数字放进叫 age 的盒子里

⚠️

x = x + 1 不是矛盾方程

它的意思是：把 x 里的值拿出来加1，再放回 x

常见赋值方式

score = 85

直接赋值

score = score + 5

用自身值更新

score += 10

input() 与类型转换

⚠️

input() 获取的永远是字符串！
不管你输入 18 还是 3.14，返回的都是字符串

input_demo.py
# 获取用户输入
age = input("年龄: ")
print(type(age)) # str!

类型转换函数

int() 转换为整数
float() 转换为浮点数
str() 转换为字符串

int("18") → 18   |   str(100) → "100"

variables.py 基础

name → <class 'str'>
age → <class 'int'>
height → <class 'float'>
is_student → <class 'bool'>

type() 在调试时特别有用，可以帮你确认变量的类型
