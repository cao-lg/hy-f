什么是编程？

编程是用计算机能听懂的语言，一步一步地告诉它该做什么。

想象一下，你面前坐着一个特别听话的机器人。你说什么它就做什么，绝不还嘴。但你得把每一步都说清楚，少一步它就愣在那儿了。

🤖 机器人的特点

  • 绝对听话，你说什么它就做什么
  • 非常笨，需要非常具体的指令
  • 不会「猜」你的意思
  • 每一句指令都必须清晰明确

为什么选择 Python？

接近人话，容易学习

看！就这么简单，一行代码就能让计算机说话

Python 的优势

✓ 语法简单，接近自然语言
✓ 应用广泛，各行各业都在用
✓ 社区活跃，学习资源丰富
✓ 人工智能、数据分析首选语言
